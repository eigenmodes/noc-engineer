# Rafiki capability document — HTML

- `rafiki-long.html` — pages 1+2 as one long page (email).
- `rafiki-two-pages.html` — two 1240×1880 pages; browser Print → Save as PDF gives a 2-page PDF.
- `img/` — logo, illustration, favicon used by both files.
- `screenshots/` — put screenshot files here (names in the LLM guide).
- `LLM-INSERT-SCREENSHOTS.md` — instructions for an LLM to fill the 4 screenshot slots.

Fonts (Heebo, Nunito) load from Google Fonts; offline, a fallback font is used.
